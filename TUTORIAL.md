## Введение

**"Большое путешествие"** (Big Trip) — это веб-приложение для планирования и организации путешествий. Приложение позволяет создавать, редактировать и управлять маршрутными точками вашего путешествия, включая различные виды транспорта, размещение, экскурсии и другие активности.

### Основные возможности:
- ✈️ Планирование маршрута с различными типами событий
- 🗓️ Управление датами и временем
- 💰 Учёт стоимости поездки
- 🔄 Фильтрация и сортировка событий
- 📱 Современный адаптивный интерфейс
- 🌐 Синхронизация с внешними API

## Установка и запуск

### Системные требования
- **Node.js** версии 20 или выше
- **npm** (устанавливается вместе с Node.js)
- Современный веб-браузер (Chrome, Firefox, Safari, Edge)

### Установка

1. **Клонируйте репозиторий или скачайте архив проекта**
```bash
git clone https://github.com/shevtsovsv/01.git
cd 01
```

2. **Установите зависимости**
```bash
npm install
```

### Запуск приложения

#### Режим разработки
```bash
npm start
```
Приложение откроется в браузере по адресу: `http://localhost:8080`

#### Сборка для продакшена
```bash
npm run build
```
Собранные файлы будут в папке `build/`

#### Проверка кода
```bash
npm run lint
```

### ⚠️ Важное примечание об API

Приложение предназначено для работы с внешними API-сервисами:
- **API точек маршрута**: `https://21.objects.htmlacademy.pro/big-trip/points`
- **API направлений**: `https://21.objects.htmlacademy.pro/big-trip/destinations`  
- **API предложений**: `https://21.objects.htmlacademy.pro/big-trip/offers`

**Если API недоступны**, приложение будет показывать экран "Click New Event to create your first point", но функционал создания событий будет ограничен.

### Режим с демонстрационными данными

В папке `src/mock/` содержатся файлы с примерами данных:
- `points.js` — образцы событий путешествия
- `destination.js` — примеры направлений с описаниями и фотографиями  
- `offers.js` — каталог дополнительных услуг для каждого типа события

Для разработчиков: эти файлы можно использовать для локального тестирования функциональности.

## Создание новых событий

### Шаг 1: Открытие формы создания

1. Нажмите на кнопку **"+ New event"** в правом верхнем углу
2. Откроется форма создания нового события

### Шаг 2: Заполнение основной информации

#### Выбор типа события
Доступные типы событий:
- **🚕 Taxi** — поездка на такси
- **🚌 Bus** — автобусное сообщение
- **🚂 Train** — железнодорожный транспорт
- **🚢 Ship** — водный транспорт
- **🚗 Drive** — поездка на автомобиле
- **✈️ Flight** — авиаперелёт
- **🏨 Check-in** — размещение в отеле
- **🏛️ Sightseeing** — экскурсии и осмотр достопримечательностей

#### Указание места назначения
1. Выберите пункт назначения из выпадающего списка
2. Или начните вводить название — система предложит варианты
3. Для новых направлений может потребоваться ручной ввод

#### Установка даты и времени
- **Дата начала** — выберите дату начала события
- **Время начала** — укажите точное время
- **Дата окончания** — выберите дату завершения
- **Время окончания** — укажите время завершения

### Шаг 3: Дополнительные опции

#### Цена
- Введите стоимость события в евро
- Можно указать 0, если событие бесплатное

#### Дополнительные услуги (Offers)
Для каждого типа события доступны специфические дополнительные услуги:
- **Для такси**: "Order Uber", "Switch to comfort class"
- **Для полётов**: "Add luggage", "Switch to comfort class", "Add meal"
- **Для отелей**: "Add breakfast", "Laundry"

#### Описание места
При выборе направления может отображаться:
- Описание места
- Фотографии достопримечательностей
- Дополнительная информация

### Шаг 4: Сохранение события

1. Нажмите кнопку **"Save"** для сохранения
2. Или **"Cancel"** для отмены создания
3. Или **"Delete"** для удаления (если редактируете существующее событие)

## Управление существующими событиями

### Просмотр событий

События отображаются в виде карточек со следующей информацией:
- **Дата** — дата события (например, "MAR 18")
- **Тип и иконка** — визуальное обозначение типа
- **Название** — тип события + направление (например, "Flight Chamonix")
- **Время** — период проведения события
- **Продолжительность** — автоматически рассчитывается
- **Стоимость** — цена в евро
- **Дополнительные услуги** — список активных опций
- **Кнопка избранного** — звёздочка для отметки важных событий
- **Кнопка развёртывания** — для редактирования

### Редактирование события

1. Нажмите на кнопку **стрелки вниз** (rollup button) на карточке события
2. Событие развернётся в режим редактирования
3. Измените необходимые поля
4. Сохраните изменения кнопкой **"Save"**

### Форма редактирования события

![Big Trip форма редактирования](https://github.com/user-attachments/assets/c7aa9e15-647f-4e73-9cfa-80beab9c9d61)

В режиме редактирования доступны:
- **Выбор типа события** — выпадающий список с иконками
- **Поле назначения** — автодополнение с предложениями
- **Даты и время** — поля "From" и "To" с календарем  
- **Цена** — поле для ввода стоимости в евро
- **Дополнительные опции** — чекбоксы с ценами
- **Описание места** — автоматически загружается для выбранного направления
- **Кнопки управления** — Save, Delete, Cancel

### Добавление в избранное

1. Нажмите на **звёздочку** в правом верхнем углу карточки события
2. Активная звёздочка будет выделена цветом
3. Избранные события можно использовать для быстрого доступа

### Удаление события

1. Откройте событие для редактирования
2. Нажмите кнопку **"Delete"**
3. Подтвердите удаление

## Фильтрация событий

Фильтры находятся в верхней части приложения и позволяют отобразить только определённые типы событий:

### Типы фильтров

#### Everything (Всё)
- Показывает все созданные события без исключения
- Выбран по умолчанию
- Счётчик показывает общее количество событий

#### Future (Будущие)
- Отображает только события, которые начинаются в будущем
- Полезно для планирования предстоящих активностей
- Автоматически обновляется в зависимости от текущей даты

#### Present (Текущие)
- Показывает события, которые происходят прямо сейчас
- Событие считается текущим, если текущее время находится между временем начала и окончания

#### Past (Прошедшие)
- Отображает завершённые события
- Полезно для анализа пройденного маршрута
- Включает все события, время окончания которых уже прошло

### Использование фильтров

1. Кликните на нужный фильтр в верхней панели
2. Список событий автоматически обновится
3. Счётчик покажет количество событий в выбранной категории
4. Неактивные фильтры (с 0 событий) будут отключены

## Сортировка событий

Когда в приложении есть события, появляется панель сортировки с несколькими опциями:

### Типы сортировки

#### Day (По дню)
- **Активна по умолчанию**
- Сортирует события по дате начала (от ранних к поздним)
- Лучший вариант для планирования маршрута по дням

#### Time (По времени)
- Сортирует события по продолжительности
- От самых коротких к самым длинным
- Полезно для оптимизации расписания

#### Price (По цене)
- Сортирует события по стоимости
- От самых дорогих к самым дешёвым
- Помогает в планировании бюджета

#### Offers (По предложениям)
- **Недоступна для использования** (кнопка отключена)
- Зарезервирована для будущих обновлений

### Как использовать сортировку

1. Создайте несколько событий
2. Панель сортировки появится автоматически
3. Кликните на нужный тип сортировки
4. События перестроятся в соответствии с выбранным критерием

## Типы событий и опции

### Транспортные события

#### 🚕 Taxi (Такси)
- **Назначение**: Короткие поездки по городу
- **Дополнительные опции**:
  - Order Uber — заказ через приложение
  - Switch to comfort class — повышение класса комфорта
- **Особенности**: Обычно короткие по времени, умеренная стоимость

#### 🚌 Bus (Автобус)
- **Назначение**: Междугородние и городские маршруты
- **Дополнительные опции**:
  - Add luggage — дополнительный багаж
  - Switch to comfort class — места повышенной комфортности
- **Особенности**: Экономичный вариант для длинных расстояний

#### 🚂 Train (Поезд)
- **Назначение**: Железнодорожные путешествия
- **Дополнительные опции**:
  - Add luggage — дополнительные места багажа
  - Switch to comfort class — купе или СВ
  - Add meal — питание в пути
- **Особенности**: Комфортабельный транспорт для средних и длинных расстояний

#### 🚢 Ship (Корабль)
- **Назначение**: Водные путешествия, паромы, круизы
- **Дополнительные опции**:
  - Add luggage — дополнительный багаж
  - Add meal — питание на борту
  - Switch to comfort class — каюта повышенной комфортности
- **Особенности**: Длительные маршруты, высокая стоимость

#### 🚗 Drive (Автомобиль)
- **Назначение**: Поездки на собственном или арендованном авто
- **Дополнительные опции**:
  - Rent a car — аренда автомобиля
  - Add insurance — страховка
  - GPS navigation — навигационная система
- **Особенности**: Максимальная свобода передвижения

#### ✈️ Flight (Полёт)
- **Назначение**: Авиаперелёты
- **Дополнительные опции**:
  - Add luggage — дополнительный багаж
  - Switch to comfort class — бизнес или первый класс
  - Add meal — специальное питание
  - Choose seats — выбор мест
- **Особенности**: Быстрые, но обычно самые дорогие

### События размещения и активностей

#### 🏨 Check-in (Размещение)
- **Назначение**: Отели, хостелы, апартаменты
- **Дополнительные опции**:
  - Add breakfast — завтрак включён
  - Laundry — услуги прачечной
  - Internet — Wi-Fi
  - Parking — парковка
- **Особенности**: Длительность обычно в днях

#### 🏛️ Sightseeing (Экскурсии)
- **Назначение**: Осмотр достопримечательностей, музеи, туры
- **Дополнительные опции**:
  - Book tickets — предварительная покупка билетов
  - Lunch — обед в ходе экскурсии
  - Private guide — персональный гид
  - Audio guide — аудиогид
- **Особенности**: Обычно несколько часов, культурная программа

## Работа с предложениями и направлениями

### Система направлений (Destinations)

#### Автоматические предложения
- При вводе названия города система предлагает варианты
- Данные загружаются с внешнего API
- Включают описания и фотографии мест

#### Информация о направлениях
Для каждого направления может быть доступна:
- **Описание места** — краткая информация о городе/стране
- **Фотографии** — изображения достопримечательностей
- **Рекомендации** — советы по посещению

#### Добавление новых направлений
1. Начните вводить название в поле назначения
2. Если место не найдено, можно ввести вручную
3. Новые направления сохраняются для последующего использования

### Система предложений (Offers)

#### Категории предложений
Предложения привязаны к типам событий:
- **Транспортные услуги** — багаж, питание, класс обслуживания
- **Размещение** — завтрак, дополнительные услуги
- **Развлечения** — билеты, гиды, специальные программы

#### Управление предложениями
1. При создании/редактировании события выберите тип
2. Доступные предложения отобразятся ниже
3. Отметьте нужные опции галочками
4. Стоимость предложений добавится к общей цене события

#### Стоимость предложений
- Каждое предложение имеет свою стоимость
- Общая стоимость события = базовая цена + стоимость выбранных предложений
- Стоимость предложений отображается рядом с названием

## Управление данными

### Локальное хранение
- Данные сохраняются в браузере автоматически
- События остаются доступными между сессиями
- Очистка кеша браузера удалит все данные

### Синхронизация с сервером

#### API-интеграция
Приложение работает с внешними сервисами:
- **Точки маршрута** — синхронизация событий
- **Направления** — база данных мест
- **Предложения** — каталог дополнительных услуг

#### Статусы синхронизации
- **Загрузка** — отображается spinner при загрузке данных
- **Ошибка соединения** — сообщение при проблемах с сетью
- **Офлайн режим** — работа с локальными данными

### Экспорт и импорт данных

#### Автоматическое сохранение
- Все изменения сохраняются мгновенно
- Нет необходимости в ручном сохранении
- Данные синхронизируются с сервером при наличии подключения

#### Резервное копирование
Рекомендуется периодически:
1. Проверять доступность данных в приложении
2. Делать скриншоты важных маршрутов
3. Сохранять информацию о ключевых событиях отдельно

## Устранение неполадок

### Частые проблемы и решения

#### Приложение не загружается
**Симптомы**: Белый экран или ошибка загрузки
**Решения**:
1. Проверьте подключение к интернету
2. Обновите страницу (Ctrl+F5 или Cmd+R)
3. Очистите кеш браузера
4. Попробуйте другой браузер

#### Данные не сохраняются
**Симптомы**: Созданные события пропадают
**Решения**:
1. Проверьте, что JavaScript включён в браузере
2. Убедитесь, что браузер поддерживает localStorage
3. Проверьте настройки приватности браузера
4. Попробуйте режим инкогнито для тестирования

#### Ошибки при создании событий
**Симптомы**: Форма не сохраняется или показывает ошибки
**Решения**:
1. Проверьте правильность заполнения всех обязательных полей
2. Убедитесь, что дата окончания позже даты начала
3. Проверьте корректность введённой стоимости
4. Попробуйте обновить страницу и создать событие заново

#### Кнопка "New Event" не работает
**Симптомы**: При нажатии на кнопку ничего не происходит, в консоли ошибки API
**Причина**: Внешние API-сервисы недоступны или заблокированы
**Решения**:
1. Проверьте консоль браузера (F12 → Console) на наличие ошибок сети
2. Убедитесь что адреса API доступны:
   - `https://21.objects.htmlacademy.pro/big-trip/points`
   - `https://21.objects.htmlacademy.pro/big-trip/destinations`
   - `https://21.objects.htmlacademy.pro/big-trip/offers`
3. Если API недоступны, приложение будет работать в ограниченном режиме

#### Проблемы с API
**Симптомы**: Не загружаются направления или предложения, ошибки в консоли
**Что происходит**: Приложение пытается загрузить данные с внешних серверов:
```
Failed to load resource: net::ERR_BLOCKED_BY_CLIENT.Inspector
Can not load destinations TypeError: Failed to fetch
Can not load offers TypeError: Failed to fetch
```
**Решения**:
1. Проверьте стабильность интернет-соединения
2. Попробуйте отключить блокировщики рекламы
3. Подождите несколько минут и попробуйте снова
4. Приложение может работать в автономном режиме с ограниченной функциональностью

## Техническая информация для разработчиков

### Архитектура приложения

#### Паттерн MVP (Model-View-Presenter)
- **Models** — управление данными и бизнес-логикой
- **Views** — отображение интерфейса пользователя  
- **Presenters** — связующее звено между моделями и представлениями

#### Ключевые модули

**Модели данных**:
- `PointModel` — управление событиями маршрута
- `FilterModel` — состояние фильтров
- `DestinationModel` — справочник направлений
- `OffersModel` — каталог предложений

**Представления (Views)**:
- `BoardView` — основная панель приложения
- `EventListView` — список событий
- `FiltersView` — панель фильтров
- `SortsView` — панель сортировки
- `EditEventView` — форма редактирования событий

**Презентеры (Presenters)**:
- `BoardPresenter` — основной контроллер приложения
- `PointPresenter` — управление отдельными событиями
- `FilterPresenter` — логика фильтрации

3. Добавьте соответствующую логику в `FilterPresenter`
